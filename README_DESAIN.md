# Kaisar Naga Abyss — ZEPETO clothing concept

Original fantasy robe blockout created for this project. The design uses an original abstract crest and geometric ornament; it is not intended to copy a named donghua, game, character, logo, or franchise.

## Design direction
- Long black outer robe with crimson front panels and lining.
- High collar, wide sleeves, gold trim, shoulder ornaments, and waist sash.
- Original abstract chest crest.

## Project files
- `assets/kaisar_naga_abyss.obj` — editable Wavefront OBJ static mesh blockout.
- `assets/kaisar_naga_abyss.mtl` — black silk, crimson, and antique-gold materials.
- `ZEPETO_FITTING_GUIDE.md` — avatar fitting, rigging, and optimization checklist.

## Current status
The OBJ is an early static mesh blockout, **not yet a ZEPETO-ready wearable**. It has not been fitted to the official avatar base, UV-unwrapped, rigged, weight-painted, or validated in ZEPETO Studio.

## Next production stage
Use the official ZEPETO creator base FBX, mask, and armature. Follow the fitting and rigging steps in `ZEPETO_FITTING_GUIDE.md`. Check the current official Studio documentation before export and submission.
