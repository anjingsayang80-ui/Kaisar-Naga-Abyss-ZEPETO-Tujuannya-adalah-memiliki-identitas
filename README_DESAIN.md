# Kaisar Naga Abyss — ZEPETO clothing concept

Original fantasy robe blockout created for this project. It uses a custom abstract crest and geometric ornament; it is not copied from a named donghua, game, or character.

## Files
- `assets/kaisar_naga_abyss.obj` — editable Wavefront OBJ mesh blockout.
- `assets/kaisar_naga_abyss.mtl` — black silk, crimson, and antique-gold materials.

## Design direction
- Long black outer robe with crimson front panels and lining.
- High collar, wide sleeves, gold trim, shoulder ornaments, and waist sash.
- Original abstract chest crest.

## Important status
This is an early static mesh blockout, **not yet a ZEPETO-ready wearable**. It has no avatar skinning/rig, weight painting, UV texture atlas, or platform validation. Those steps are required before upload. Check the current ZEPETO Studio clothing requirements before publishing.

## Import
Import the OBJ into a 3D editor that supports Wavefront OBJ and keep the MTL in the same relative folder. Inspect scale, normals, and mesh intersections before further work.
